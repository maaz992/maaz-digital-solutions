# Maaz Digital Solutions (MDS)

A responsive, premium purple-themed static website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, colors, and visual design
- `script.js` — mobile menu, reveal animations, year, and email inquiry form

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` in `BUSINESS_EMAIL` with your actual business email.
3. Review the service list and remove any services you are not ready to deliver.
4. Replace the demonstration portfolio concepts with real work when available. The current concepts are clearly marked as demos.
5. Add your actual social links and business contact details if desired.

## Preview locally
Open `index.html` in a browser. For a local server, you can use VS Code's Live Server extension.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `maaz-digital-solutions`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.

## Contact form limitation
This is a static website. After configuring `BUSINESS_EMAIL`, the form prepares an email through the visitor's default email app; it does not send or store submissions by itself. For a form that submits directly on the website, connect a form service or backend and update the form handler.
